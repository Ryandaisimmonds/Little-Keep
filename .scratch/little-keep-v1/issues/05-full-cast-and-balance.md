# 05: Full cast and balance

**What to build:** The first complete version's content, balanced. Six Familiars with about four Skills each (every Skill with a Master Form), about twelve Hero types, three mid-bosses and three bosses, and a full set of story events. A bot plays whole Runs and reports win rate and length, and tuning is adjusted until a Run takes 20 to 25 minutes with sensible win rates on each difficulty tier. See the spec's scope section.

**Blocked by:** 03 Keep, 04 Elements and Combos

**Status:** ready-for-agent

- [ ] Six Familiars, each with about four Skills spread across the four Elements, every Skill with a Master Form
- [ ] Three Familiars owned at the start; the other three each have a Deed or a Bond
- [ ] About twelve Hero types with distinct behaviour, some bringing a creature; three mid-bosses and three bosses
- [ ] Enough story events and shop stock that consecutive Runs differ
- [ ] A Run bot plays whole Runs through the rule modules and reports win rate and Run length per difficulty tier
- [ ] Bot results and tuning changes are recorded in the repo
- [ ] A typical Run takes 20 to 25 minutes
- [ ] All content is data assets the developer can edit in the Inspector
- [ ] Milestone 4 build installed and played on the developer's phone
